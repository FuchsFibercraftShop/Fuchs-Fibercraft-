Fuchs Fibercraft — Donation Shop

This repo contains a simple static shop (HTML/CSS/JS) styled in a black / purple / pink neon theme.

What I created:
- index.html: shop layout and product placeholders
- styles.css: neon theme, animations
- script.js: frontend cart stored in localStorage and basic checkout behavior

Quick notes / next steps for you:
1) Replace PAYPAL_LINK in script.js with your PayPal.Me or PayPal payment link so the checkout button opens your payment page.
2) Replace the logo placeholder in index.html with your own image (add file to /assets/logo.png or change the HTML).
3) If you want the shop hosted at terrorfibercraft.com, tell me and provide DNS access or configure an A/CNAME to point to GitHub Pages; I can add a CNAME file after you confirm.
4) For real persistent stock/orders you need a backend (I can add Firebase or a tiny server later).

Hosting with GitHub Pages:
- You can enable Pages in repository settings (branch: main, folder: /). After that the site will be available at https://FuchsFibercraftShop.github.io/Fuchs-Fibercraft-/
- If you want your custom domain, tell me "use domain" and I'll add CNAME and instructions.
